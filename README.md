# NovaSwap — Crypto Exchange MVP

Демонстрационный интерфейс криптообменника.

## Запуск
1. Установите Node.js 20+.
2. В этой папке выполните:
   `npm install`
3. Запустите:
   `npm run dev`
4. Откройте `http://localhost:3000`.

## Важно
Это UI/MVP. Реальные деньги, криптокошельки, KYC/AML, платежи и blockchain-транзакции не подключены.
Для production потребуется backend, БД, аутентификация, аудит, безопасность, KYC/AML и соответствующая лицензия/правовая структура.
